## First upload

1. On GitHub, create a **public repository** named exactly:

   `Abdulrehman-glitch`

2. Upload the contents of this folder to that repository.  
   `README.md` must remain in the repository root.

3. Commit the files to the `main` branch.

4. Open the repository's **Actions** tab.

5. Open **Update live profile** and select **Run workflow** once.

After that first run, the placeholder statistics and activity panels will be replaced by verified data from your GitHub account. The workflow will then refresh them daily.
